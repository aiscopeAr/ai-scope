Duplicate: /category/tutorials

Confirmed duplicate

Appears once as a hardcoded static entry and again from the dynamic category loop, since "tutorials" independently qualifies with 11 reviews (_count.reviews > 0).

app/sitemap.ts line 18 (static) + line 66 (dynamic loop)

Excluded by design: 6 empty categories, all paginated listing URLs

Deliberate, not a bug

The sitemap generator filters categories to _count.reviews > 0, correctly keeping the 6 zero-content categories out of the sitemap. It does not, however, emit ?page=2 etc. for /reviews or /prompts — a defensible choice per Google's own guidance (paginated listings don't need sitemap entries when the underlying items are already listed individually), but worth stating as a deliberate omission, not an oversight.

No hard indexing block exists anywhere tested. Zero noindex directives, zero X-Robots-Tag headers, zero server-side redirects on any of the 21 URLs above. Every gap found in this audit is a content/architecture problem — thin pages, missing sitemap entries, weak internal links — never a technical block that literally prevents crawling.

Verdict

"If Google had unlimited crawl budget today, how many pages should be indexed?"

~715 of ~730 generated URLs
Should index · ~15 should not, by design or by content quality

The math

BucketCountShould index?
Reviews, tools, prompts, comparisons, tags, populated categories, populated use-cases, authors, static pages705Yes — content-bearing, technically clean
Empty categories (6) + empty use-cases (3)9No — zero content, should 404 or redirect instead of 200
/category/tutorials duplicate sitemap entry1Not a separate URL — same page counted twice
Reviews/prompts pagination pages (not in sitemap, reachable by crawl)~21Yes, but currently depend on crawl discovery rather than sitemap

The gap between "~730 generated" and "~715 should index" is small and specific: it is exactly the 9 pages identified in §4 that render 200 with genuinely zero content. Every other URL on the site — all 236 reviews, all 51 tools, all 272 prompts, all 57 tags, all 4 comparisons — is technically indexable today with a correct canonical and no robots block. The ceiling on actual Google indexing is not a code defect at this point; per the GSC evidence cited elsewhere, it is dominated by crawl frequency and domain authority for a young site — factors this audit's read-only scope doesn't reach, but which are visibly separate from the architecture question this report was scoped to answer.
