# דוח Google Search Console

דשבורד לוקאלי למעקב ביצועי SEO של lumiq.news, בנוי מקבצי ה-CSV שגוגל סירש קונסול מאפשרת לייצא (Performance → Export → Download CSV).

## קבצים

- `gsc-report.html` — הדשבורד עצמו (KPIs, מגמה יומית, מדינות, מכשירים, עמודים, שאילתות).
- `gsc-snapshots.json` — כל תמונות המצב שנשמרו עד כה, מערך `snapshots` ממוין כרונולוגית.

## איך צופים בדוח

הדוח טוען את ה-JSON דרך `fetch()`, כך שהוא **לא** ייפתח נכון כ-`file://` (חסימת CORS של הדפדפן). יש להגיש אותו משרת לוקאלי:

```bash
cd docs/seo
python -m http.server 8934
# ואז לפתוח http://localhost:8934/gsc-report.html
```

(אפשר גם `npx serve .` או Live Server ב-VS Code — כל שרת סטטי מספיק.)

## איך מוסיפים תמונת מצב חדשה

1. לייצא מ-Search Console: Performance → בחר טווח תאריכים וסוג חיפוש → Export → Download CSV. חשוב לוודא שהקידוד הוא UTF-8 (במיוחד בשביל שאילתות בערבית — ראו "בעיה ידועה" למטה).
2. להדביק את תוכן ה-CSVs בשיחה עם קלוד ולבקש לעדכן את הדוח.
3. קלוד יוסיף אובייקט `snapshot` חדש למערך ב-`gsc-snapshots.json` (עם `capturedAt` של תאריך היום), מבלי לגעת בתמונות המצב הקודמות.
4. ברענון הדף, ברגע שיש 2+ תמונות מצב, יופיע בורר תמונת מצב למעלה, וכל KPI יציג דלתא (▲/▼) לעומת תמונת המצב הקודמת.

## בעיה ידועה — קידוד תווים בשאילתות ערביות

ב-2026-07-02 קובץ `Queries.csv` הודבק עם קידוד פגום (mojibake) — כל השאילתות בערבית הופיעו כג'יבריש בלתי הפיך (למשל `ÙÙÙÙÙ`). זה קרה כי הטקסט עבר דרך העתקה/הדבקה שאיבדה את בייטי ה-UTF-8 המקוריים. **הפתרון: לצרף את קובץ ה-CSV כקובץ מצורף (attachment) ולא כטקסט מודבק**, או לוודא שהאפליקציה ששולפת ומעתיקה את הטקסט שומרת UTF-8 תקין.
